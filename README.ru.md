cburn следит за каждой сессией Claude Code на машине и превращает транскрипты в
живую картину того, куда уходят токены. Стрелка ползёт вверх, пока Claude работает,
и плавно опадает в тишине; вокруг неё - итоги дня, стоимость по тарифам API, окна
лимитов подписки и сессии в работе.

Всё происходит локально: транскрипты читаются прямо из `~/.claude/projects`, а
текст переписки не покидает машину.

## Установка

Готовой сборки пока нет - `brew install` и `.app` в релизах стоят следующими в
очереди. Сегодня cburn собирается из исходников:

```bash
git clone https://github.com/Cloudo/cburn.git && cd cburn
make install   # .venv, установка пакета и зависимости npm
make web       # сборка фронтенда в web/dist
make reindex   # чтение транскриптов в базу
make serve     # дашборд на http://127.0.0.1:8799
```

`cburn install` добавляет автозапуск при входе через launchd. Приложение для
строки меню собирается отдельно и требует Rust:

```bash
make desktop-build   # .app появится в src-tauri/target/release/bundle/macos
```

Оно не подписано, поэтому при первом запуске macOS держит его на расстоянии:
откройте из Finder правым щелчком и "Открыть" либо снимите карантин руками.

```bash
xattr -dr com.apple.quarantine src-tauri/target/release/bundle/macos/cburn.app
```

## Требования

macOS 13 или новее, Apple Silicon или Intel. Python 3.11+ и Node для сборки, Rust
только ради приложения в строке меню. И, разумеется, сам Claude Code: cburn читает
транскрипты, которые тот оставляет в `~/.claude/projects`, и никогда туда не пишет.

## Зачем

Посчитать токены задним числом просто, и это умеет не одна утилита. Дорого стоит
другой вопрос: что горит **прямо сейчас** и что с этим делать. cburn отвечает
стрелкой, которая трогается через секунду после того, как ход лёг в транскрипт;
окнами лимитов, взятыми у Anthropic, а не угаданными; и советником, который раз в
час читает обезличенный дайджест и говорит, где контекст ушёл впустую.

## Что умеет

- **Живой прибор** - расход по вебсокету, стрелка трогается через секунду после появления хода в транскрипте.
- **Стоимость и итоги** - токены по видам, доллары по тарифам API, модели и инструменты дня.
- **Лимиты подписки** - пятичасовое и недельные окна, обновляются с сервера Anthropic.
- **Советник** - раз в час `claude -p` читает обезличенный дайджест и предлагает оптимизации, при желании с уведомлениями в телеграм.
- **Строка меню** - обёртка на Tauri выносит выбранные вами цифры в menu bar macOS.
- **Приёмник OTLP** - берёт телеметрию Claude Code там, где транскрипты молчат.

## Телеметрия (по желанию)

Claude Code умеет отдавать метрики и события по OTLP, и в cburn есть приёмник для
них. Телеметрия закрывает то, чего нет в файлах истории: служебный расход, который
не доходит до транскрипта (заголовок сессии стоит отдельного вызова haiku), сколько
раз работа вставала на подтверждение разрешения, точные цены и длительности
запросов, время внутри инструментов и хуков.

По умолчанию она выключена, потому что включить её может только окружение самого
Claude Code - cburn не пишет в чужой конфиг. Напечатайте готовые строки, вставьте
их в профиль оболочки или в `settings.json` и перезапустите Claude Code:

```bash
cburn otel --env
```

Всё остаётся на машине: экспортёр смотрит на локальный приёмник внутри
`cburn serve`, а тексты запросов и ответов отбрасываются при разборе - хранятся
только счётчики и длительности. Без телеметрии дашборд просто считает по-старому,
по одним транскриптам.

## Приватность

До советника доходят только имена инструментов, нормализованные команды, пути и
числа; то, что вы набрали, остаётся на вашем экране. `~/.claude` для cburn открыт
только на чтение, единственное исключение - применение совета, который вы
подтвердили, и всегда с резервной копией и откатом.

## Частые вопросы

**После клонирования дашборд пустой.** Фронтенд не хранится в репозитории:
выполните `make web` один раз, и по `/` откроется страница, а не список эндпоинтов.

**"лимиты недоступны: нет токена Claude Code в связке ключей".** Лимиты приходят с
того же эндпоинта, которым пользуется `/usage`, с OAuth-токеном, который Claude
Code держит в связке ключей. Это же сообщение появляется, когда запрос вообще не
ушёл с машины: если токен на месте, причина найдётся в
`~/.local/share/cburn/serve.log`.

**`make desktop` отказывается запускаться.** Приложение живёт в одном экземпляре,
поэтому второй запуск передался бы тому, что уже в трее. Закройте его там и
повторите команду.

**Где что лежит.** Скажет `cburn paths`: база и лог в `~/.local/share/cburn`,
конфиг в `~/.config/cburn/config.toml`. Транскрипты остаются там, где их оставил
Claude Code.

## Удаление

```bash
cburn uninstall                              # агент автозапуска
rm -rf ~/.local/share/cburn ~/.config/cburn  # база, лог и конфиг
```

Приложение, если вы перенесли его в `/Applications`, отправляется в корзину как
любое другое. Внутри `~/.claude` от cburn не остаётся ничего.

## Разработка

Голая `make` печатает весь инструментарий: проверки (`make check` перед каждым
коммитом), фронтенд с горячей перезагрузкой, окно приложения, приёмник телеметрии.
`make demo` поднимает второй дашборд на синтетическом наборе - снимки выше сделаны
на нём. Что сделано и что впереди - в [дорожной карте](ROADMAP.md), а требования
подробно - в [спецификации](SPEC.md).
